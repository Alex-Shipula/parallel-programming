## Lab 2 — асинхронний диспетчер завдань із пріоритетами

Запуск:
```
cd lab_2
dotnet run -c Release
```
Файли:
* `TaskPriority.cs` — рівні пріоритету (`High`, `Normal`, `Low`)
* `DispatcherTask.cs` — модель задачі (id, назва, пріоритет, продюсер, час створення, делегат `Func<CancellationToken, Task>`)
* `ConsoleLog.cs` — вивід хронології подій із часовою позначкою
* `PriorityTaskDispatcher.cs` — диспетчер на `System.Threading.Channels`: три обмежені канали (по одному на пріоритет), канал-сигнал, пул воркерів, зворотний тиск (`BoundedChannelFullMode.Wait`), `Complete()` для Graceful Shutdown
* `Program.cs` — два сценарії:
  1. задача `High` обходить чергу з `Low` і береться першим вільним воркером;
  2. три продюсери з різними пріоритетами та затримками, backpressure, задача з помилкою, коректна зупинка та перевірка, що всі додані задачі опрацьовано

Принцип роботи пріоритетів: продюсер пише задачу в канал свого пріоритету, а потім надсилає сигнал. Воркер, отримавши сигнал, бере задачу в порядку `High` → `Normal` → `Low`.
